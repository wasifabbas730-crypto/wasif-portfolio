### 1. 🌊 Interactive 3D Flowing Waves (Three.js + GLSL)
- **3D Displaced Mesh:** Uses the user's abstract neon green wave artwork loaded directly as a high-resolution WebGL texture on a $160 \times 160$ polygon grid.
- **Custom Shaders:** Multi-frequency harmonic wave equations displace the surface in real time with liquid UV flow and silky crest bioluminescence against deep obsidian black.
- **Interactive Cursor Physics:** Mouse movements and swipes create physical wave disturbances and ripple dynamics that follow the cursor.
